# Probability with Measure Theory

Lecture notes on probability theory with measure theory, with proofs, exercises and interactive
Python demos, by [Alberto Gennaro](https://gennaroalberto.github.io/).

These notes are an English translation, rearrangement and digitisation of the handwritten lecture
notes of **Paola Siri**'s course in probability theory: the structure, definitions, theorems, proofs
and examples are hers. I added the exercises (some computational, some adapted from Sheldon Ross,
*A First Course in Probability*), the Python demos and references for results stated without proof.
I learnt probability with these notes, and to this day they are still among my favourite notes to read.

**Read online:** [lecture notes (PDF)](https://gennaroalberto.github.io/probability-measure-theory/notes.pdf) ·
[exercises (PDF)](https://gennaroalberto.github.io/probability-measure-theory/exercises.pdf) ·
[download page](https://gennaroalberto.github.io/probability-measure-theory/)

The PDFs are rebuilt from the LaTeX sources on every push, after the code tests and the notebooks have run.

## Layout

```
latex/
  toc.tex            the chapters, in order: one list drives every PDF
  chapters/          lecture notes, one file per chapter
  exercises/         exercises, one file per chapter (statements only)
  figures/           figures, generated by code/figures/
  coursenotes.sty    shared style: statements, exercises, links to the code
code/
  src/probnotes/     a small Python package used by the notebooks and figures
  notebooks/         interactive demos, one or more per chapter
  figures/           scripts that draw the figures in the notes
  tests/             checks of the code against closed-form results
```

## Run the demos

Each notebook opens in Google Colab from the link in the notes. To run them locally:

```bash
pip install -e "code[dev]"
jupyter lab code/notebooks
```

## Build the PDFs

You need a TeX distribution (MacTeX or TeX Live) and Python 3.10 or later.

```bash
make            # figures, then latex/notes.pdf and latex/exercises.pdf
make test       # code tests
```

## Solutions

Solutions to the exercises are not published, so that the exercises keep their value for
